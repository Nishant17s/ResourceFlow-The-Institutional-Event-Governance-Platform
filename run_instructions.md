### How to Run Locally

Since the automatic run command had issues with your environment path previously, please run this command in your terminal (ensure you are in `d:/project vibeathon`):

```powershell
streamlit run app.py
```

If `streamlit` is not recognized, try:

```powershell
python -m streamlit run app.py
```
